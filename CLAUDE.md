# CLAUDE.md — iPad1MailBox

Lightweight IMAP mail client for the original **iPad 1 (iOS 5.1.1, armv7, 256 MB RAM)** — Objective-C/UIKit split view, **non-ARC**, Theos + iPhoneOS 6.1 SDK. Modern TLS comes from a bundled **Mbed TLS 3.6.7** transport (TLS 1.2, ECDHE/ECDSA + AES-GCM, SNI, hostname + X.509 chain verification) because iOS 5 SecureTransport can't talk to modern mail servers. Package `com.shapeloglu.ipad1mailbox` **0.5-alpha1** (`control`).

## Build

```bash
./scripts/bootstrap_mbedtls.sh                 # clones mbedtls-3.6.7 into Vendor/mbedtls, installs Config/IMBMBEDTLSConfig.h, fetches ISRG Root X1 into Resources/
make clean && make package FINALPACKAGE=1      # ARCHS=armv7, TARGET=iphone:clang:6.1:5.1
```

`Vendor/` is generated by the bootstrap script (not committed). Install over SSH with legacy `ssh-rsa` options.

## Code map (`Classes/`)

`IMBAccount*` (metadata + Keychain passwords) · `IMBIMAPClient` · `IMBMBEDTLSTransport` + `IMBMBEDTLSPlatform.c` (monotonic time via `mach_absolute_time`) · `IMBRFC2047Decoder` · `IMBMIMETextExtractor` · `IMBInbox/MessageList/MessageReader/Compose/AccountSetup ViewController` · `IMBTLSDiagnostics`, `IMBModernTLSProbe` (diagnostics, SecureTransport kept for comparison only).

## Rules (from TASK.md / DECISIONS.md)

- **Never weaken TLS verification** (ADR-003); SecureTransport is diagnostic-only (ADR-004).
- Passwords only in Keychain (ADR-002).
- Bounded fetches: 256 KB message prefix, 512 KB total IMAP response; never fetch whole messages/attachments unbounded.
- Current milestone does **not** add HTML rendering, SMTP, attachment download or offline cache.
- Keep app ownership narrow (ADR-008): no file manager/PDF/media features — hand off to sibling apps.
- Optimize Mbed TLS only after the feature set works (ADR-009). One transport shared by IMAP now and SMTP later (ADR-012).
- Physical-device results go into `SESSION.md`; `TASK.md` holds exactly one active task.
